# 山巅微光

原创平台跳跃原型，包含跳跃、冲刺、攀墙、体力、尖刺、收集物、快速重开、调试面板、计时练习反馈、房间分段 PB、Flow 峰值、最佳路线影子、房间 Focus 教练、Drill 练习、手柄/触控输入，以及非实体光继点、风升流、超载棱镜、回声锚点。

## 运行

在线试玩：

```text
https://lunora-gather.github.io/summit-spark/
```

```bash
npm start
```

打开：

```text
http://127.0.0.1:4173/
```

也可以直接用浏览器打开 `summit-spark.html`。

本地质量检查：

```bash
npm run check
npm run route-audit
npm run state-check
npm run browser-smoke
```

`browser-smoke` 会调用本机 Chrome/Edge 的 headless 模式，覆盖开始按钮、自由游玩 HUD 降噪、键盘打开/关闭设置、独立练习面板、反馈备注输入隔离、诊断/反馈模板、存档导出导入、导入前备份与恢复、导入预检、无效导入原地失败、直接继续训练、canvas 非空、角色位移、Feel Lab、航线合同、Route/Feel 中断恢复、坏存档恢复、移动端视觉溢出、移动房间设置裁切、竖屏触控避让、移动 visualViewport 触摸坐标、横竖屏视口和手柄死区 mock。

## 操作

- 移动：A/D 或 ←/→（触控现在也有上/下/左/右）
- 方向输入：W/S 或 ↑/↓（用于冲刺方向和攀墙）
- 跳跃：Space / C / J
- 冲刺：X / K / Shift（E 保留兼容）
- 抓墙：Z / L / Ctrl（V 保留兼容）
- 抓墙模式：设置里可在“按住”和“切换”之间切换；切换模式适合长时间练习，减少持续按键负担。
- 性能与触控：设置里可开启低性能模式，并调节触控按钮大小；两者只改变显示预算和触控尺寸，不改变判定。
- 快速下落：下方向 / S
- 回声召回：Q / Backspace（触碰回声锚点后生效）
- 键位预设：设置里可切换舒适 / 经典；经典会把 Z 作为跳跃、C 作为抓墙
- 自定义键位：控制分组可先选 Windows/Linux 或 Mac，再点击任意动作键位并按下新键；重复键会自动交换，支持恢复当前布局。
- 手柄死区：设置里可调左摇杆死区，默认 0.28，用于压住摇杆漂移但保留方向响应。
- 手柄状态：设置里显示当前浏览器是否检测到手柄、standard mapping 数量、摇杆轴强度和接近死区提示，不记录手柄 ID。
- 诊断快照：设置面板“反馈与存档”可选择反馈类型并写备注，“诊断 / 复制”会生成本地反馈摘要，包含版本、设置、进度、视口和手柄摘要，不上传数据。
- 反馈模板：“反馈与存档”可复制一段可直接贴到反馈里的模板，自动带上版本、视口、当前 Drill/Route/Feel 状态和待填写的复现项。
- 本地存档：“反馈与存档”可复制/下载 `summit-spark-save` JSON，也可粘贴同格式 JSON 导入；输入框会先预检版本、登顶数、房间 PB、Flow 和触控大小，导入会先保存一份 `summit-spark-save-backup`，可从同一面板恢复导入前备份，再走 schema 规范化并刷新页面，错误 JSON 不会刷新。
- 账号与云存档：设置里可用邮箱验证码直接注册/登录，也可使用密码登录；登录后可上传本地或载入云端进度。首次发现两端进度不同时会先要求选择，确认后设置、PB、路线、训练档案与 Flow 会自动同步。忘记密码可使用官方改密邮件，验证码创建的账号也可在登录后设置密码。
- 快速重开：R
- 当前房间重开：T
- 调试面板：F3
- 设置面板：右上角齿轮 / O
- 练习面板：右上角 ◎ / P / 启动层“练习”
- 练习辅助：设置里的“显示”可开关练习线，并调节最佳路线/ghost 透明度
- 练习目录：练习面板的房间下拉框显示 target/PB、相对 target 损失、评级、clean、Drill、技能标签和房间失误标记（`!x` / `watch`），更容易找薄弱房间。
- 练习教练：练习面板会推荐当前最该练的房间，Drill 按钮可直接进入目标练习，Reset 需要二次确认后才会清空 Focus/Drill 统计。
- Drill 状态：练习中会显示当前房间目标和本轮错误数；主 Drill 会自动解析为 Clean/Pace/Style/Expert 合同；四种变体可分别练无失误、target、房间难度类型和高手线；Expert 还会检查本房标志性动作是否真的做到了；失败会直接重开同一 Drill；Drill start/clear/clean 会写入每房统计。
- 房间详情：练习面板会展示当前房间目的、safe/fast/expert 路线、pace、clean 和 Drill 信息。
- 练习报告：练习面板会汇总 clean 进度、Drill 完成情况、Clean/Pace/Style/Expert 合约进度、训练航线、薄弱房、最大 split 损失和下一 Drill。
- 练习课表：练习面板会自动生成 Clean、Pace、Style、Expert 四张训练卡，显示每种合约的尝试/完成和进度，可一键开始对应房间 Drill。
- 房间掌握表：复盘区按优先级列出全部房间，显示 mastery 分数、pace/clean/contract 状态和建议 Drill，点击任意行可直接重练。
- 登顶复盘卡：结束画面会把下一 Drill、最大 split 损失、薄弱原因和训练航线拆成卡片，并给出具体路线建议；按钮可直接进入下一 Drill 或最慢房 Drill。
- 手柄：左摇杆 / 十字键移动，A 跳跃，B/X/RT 冲刺，肩键 / LT 抓墙，Y / Back 召回

## 开发方向

核心目标不是复刻某个现有游戏。光痕目前作为纯视觉反馈保留；光继点承担受限续航职责，只奖励冲刺、高速或续跃状态，避免无限悬空。

当前手感重点：冲刺结束后有极短的续跃窗口，能把一次冲刺转成更高的上升和横向延伸；墙跳区分普通墙跳、反向墙跳和抓墙跳，并带短墙面宽限；快速下落能压低滞空；跳、冲、抓、下落都有贴身输入回声；风升流改变空中节奏，超载棱镜把高速路线推向更高上限，回声锚点减少练习摩擦；脆冰平台会在后段短暂承重后碎裂，迫使玩家按路线节奏推进；连续触发光继点会出现连锁反馈；每个房间会记录最佳 split、评级、Flow 峰值、Focus 画像、Drill 统计和带时间轴的最佳路线影子。

第一版公开包只保留运行、发布、测试和玩家/验收文档：版本记录见 `CHANGELOG.md`；发布前检查见 `RELEASE_CHECKLIST.md`；人工试玩清单见 `PLAYTEST_CHECKLIST.md`；已知限制见 `KNOWN_ISSUES.md`。
