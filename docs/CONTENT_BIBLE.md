# Content Bible

本文件用来固定《山巅微光》的内容方向，避免后续功能越堆越散。它不是剧情大纲的最终稿，而是给设计、代码、测试和 AI 协作使用的统一标准。

## 一句话定位

《山巅微光》是一个以冲刺、攀墙、光继点和路线练习为核心的精密平台跳跃 vertical slice。玩家不是单纯通关，而是在每个房间里理解路线、压缩失误、追踪 PB、完成 Drill 合同，并通过复盘系统找到下一步训练目标。

## 核心体验

- **有界长房，高反馈**：R1–R3 用单屏教学，R4–R10 扩为约一屏半的横向长房；每房仍应在几十秒内完成，并立刻给出 split、PB、clean、Flow 或 Drill 反馈。
- **安静氛围**：自由游玩用每房一句短句、固定深蓝发色的小人和低音量章节和声建立情绪，不把叙事做成新的菜单、教程墙或过场。
- **章节必须可感知**：换幕依靠短暂的不计时呼吸、机制主题句和不同的环境运动语言完成；不得只换标题或颜色，也不得在危险判定继续运行时遮挡路线。
- **材质服务章节**：山门、旧峰、风峡与星顶应使用不同但克制的岩台表面语言；纹理必须维持顶面、危险与角色轮廓的清晰度，不伪装成新机制。
- **接触反馈延续材质**：落地、墙滑、攀墙与墙跳碎屑应沿用四幕表面语言，以石片、暖尘、冰屑和星芒区分接触质感；反馈必须短、低密度、离开接触面散开并受性能与舒缓设置约束，不改变碰撞、体力或制造新危险暗示。
- **辅助不惩罚体验、不污染竞技数据**：“舒缓”允许完整通关，但不得写入 PB、clean、Flow best、挑战、训练合同、登顶档案或最佳时间。
- **完整登顶必须来自完整路线**：只有从 R1 正式开局且本轮覆盖十房的路线才能写入登顶次数和最佳总时间；直接 Practice、调试跳房或其后继续游玩仍可记录真实房间 PB/Drill，但只能作为练习登顶。
- **Flow 分为练习与整局证据**：房间 Practice 可以更新即时/个人 Flow Best，用于手感反馈；长期“整局 Flow”挑战与长期档案只能读取完成十房正式路线时的当前轮峰值，不得把历史练习峰值回填到登顶档案。
- **四幕从每次第一步成立**：首次开局、“再来”、长期挑战与直接房间练习都必须由统一房间重置生命周期重新武装现有标题条；正式 R1 入口交代第一幕与誓句，不另加面板、不阻塞控制，后续章节继续使用章节收束/进入演出。章节房间归属与入口房只能来自规范化房间数据。
- **微光必须形成一轮闭环**：HUD 的本轮微光计数必须出现在登顶摘要和可复制报告中；当前房间拾取只在本次尝试内生效，跨过房间边界后才算安全带回。R4–R10 的中段营灯可在死亡或快速重试时保留营灯前已经验证的本房微光坐标，但不会把它提前写成永久进度，也不恢复已花掉的额外冲刺；整房重开必须让本房微光和未花费的额外冲刺一起复位。集齐全部微光时沿用第四幕收束句，并在既有长期挑战中保存正式完整路线的最佳收集数；不新增顶层成就卡或菜单。部分路线必须如实显示本轮计数，不能获得全收集结语或长期记录。
- **失败恢复不吞最后输入**：自动死亡复位必须保留复位前缓冲窗口内新按下的 Jump/Dash，让角色出现后立即执行；手动快速重开和房间重开仍要清空旧缓冲，避免把重开前动作误带入新尝试。
- **换幕输入仍须有界**：章节呼吸期间继续轮询键盘、触控和手柄，但 Jump/Dash 只能保留正常缓冲窗口；演出早期的陈旧动作必须过期，结束前最后一刻的明确动作可以自然接上新幕。
- **联网保持可选**：游客模式必须能完整游玩并使用本地存档；邮箱账号与每用户私有云存档只用于跨设备延续，网络、登录状态和云服务不得参与玩法判定。
- **可读路线优先**：难度来自路线选择和动作节奏，不来自看不清、误导 UI 或不可预测判定。
- **长房只重跑一个动作句**：R4–R10 的第二屏入口应有一个安静的世界内营灯与恢复点；失败可从营灯续上，整房重开仍回入口。营灯不得变成 HUD、永久存档或奖励复制点。
- **长房必须形成三拍**：R4–R10 的空间压力要分布为建立、转折/呼吸、综合收束三个区段。后期房间不得把超过约一半的机制压力挤在单一区段，也不得用连续同材质地毯代替新的判断；终章应允许开场回扣、营灯重整和末段综合被清楚感知。
- **可选奖励跨越两屏**：长房微光不能全部在第一屏结算；至少一部分应落在第二屏的机制支线，让营灯之后仍有风险选择。移动奖励时必须保持总数、房间归属、营灯快照校验与跨房确认规则不变。
- **训练不是菜单负担**：Practice 首屏只给选房和当前记录；路线、手感、档案与长期目标必须由玩家主动展开。
- **普通游玩安静**：普通游玩时 HUD 克制；训练和复盘中才展示更多指标。
- **本轮证据不常驻**：分房用时和失误只在内存、诊断快照与折叠复盘中出现，用来校准完整通关；不得把十房表格塞进自由游玩的常驻 HUD。
- **试玩导出必须克制**：登顶报告只含构建、时间、失误、Flow 和辅助状态，必须明确隐私边界、默认复制失败才下载，且不得自动上传或包含输入轨迹。
- **机制有边界**：光继点、风升流、超载棱镜、回声锚点、脆冰、破门、相位台和巡游晶核都应服务于路线节奏，不做无限悬空、无预警伤害或无意义特效。
- **补给必须有实际价值**：只有冲刺或攀墙体力确实缺失时才消耗补给并增加 Flow；满资源停留不得形成被动刷分点。
- **回充可读但发色固定**：冲刺从耗尽恢复时，用脚边一次短促的青色回充环确认资源就绪；不得通过头发变色、常驻角色光环或新的 HUD 提示表达，满冲刺站立也不得重复触发。
- **山门用既有地标回应所学动作**：R1 的 Spark 点亮石阶，R2 每枚首次触发的光继推进横桥，R3 的弹簧与顶点冲刺分两段唤醒雾台。反馈只存在于当前尝试的背景地标，节点冷却不能抹去进度，死亡、重开和换房必须复原；不得新增 HUD 进度、地图实体或改变动作判定。
- **房间回应动作句**：连续触发光继时，场内只用短暂光线连接本次连锁窗口内的已触发节点，让路线本身回应玩家；不得画成常驻导航线、穿透窗口继续存在或扩成 HUD 连击提示。
- **风必须托住角色而非只亮背景**：玩家进入风升流时，气流应在角色两侧形成短促上升尾迹，直接说明受力关系；反馈必须留在世界层、绘制于角色之后，并在离开风场时立即消失。
- **回声记忆留在锚点**：激活后的回声只用锚点附近的局部断环表示可召回状态，距离增加可以略增强记忆，但不得用贯穿房间的连线把锚点与角色永久相连。
- **微光在星顶形成环境闭环**：R9–R10 的既有星座应随本轮微光比例连续苏醒，让收集结果进入世界层；十二枚微光应分布在不同机制岔路，而不是重复放在每房右上终点附近。星点不得变成另一套精确计数器、成就条或改变终点判定。
- **旧峰应记住本次尝试的光继**：R4–R6 每触发一枚此前未触发的光继，既有背景遗迹应推进一次房间专属的复原；光继冷却结束不能抹掉这次尝试的痕迹，死亡、重试和换房则随房间生命周期清空。它是世界回响，不是新 HUD、永久收集或路线答案。
- **风峡脆冰以条带作出承诺**：R7–R8 踩中连续横向脆冰时，裂纹应从接触点向同一条冰带两侧短暂传播，再逐格断裂，让玩家一眼读出“必须离开整片冰面”。波纹只能连接相邻同排脆冰，不得跨空隙、跨层或扩散到 R9–R10；排队格仍保持碰撞，星顶继续保留单格触发语义。

## 当前 vertical slice 范围

当前公开 demo 是 10 房纵向切片，不是完整章节。

| 房间段 | 目标 |
| --- | --- |
| R1-R3 · 山门 | 建立跳跃、冲刺、双光继，并从与连续通关一致的左侧完整路线完成错位双弹簧幕末考试 |
| R4-R6 · 旧峰 | 首次进入横向长房，组合折返、六枚光继、三级弹簧、冲刺破门与相位台完成旧峰终考 |
| R7-R8 · 风峡 | 从稳定入口建立风与脆冰，再读取巡游晶核轨迹，末段把棱镜、破门与相位串成连续压力 |
| R9-R10 · 星顶 | 正式揭示回声，在稳定回收后组合完整工具组与三种动态障碍，并在成绩复盘前留出安静的登顶停顿 |

## 机制角色

### 跳跃 / 冲刺 / 攀墙

基础动作必须保持可靠、可预测、可练习。任何手感改动都要说明是否影响：

- coyote time
- jump buffer
- dash buffer
- dash aim memory
- wall coyote
- wall jump lock
- spark hop window

弹簧教学在 R3 建立“起跳后把冲刺留给最高点”，R6 将它放入光继组合，R10 再作为终章综合动作回扣。Style 与 Expert 只在弹簧起跳后的短窗口、且垂直速度进入顶点区间时记录 `springApex`；命中给予一次短促的世界反馈与 Flow，但不得改变弹簧力度、冲刺速度、方向判定或基础物理。窗口必须在落地、死亡、重开、换房和回声召回时清零，不能跨尝试残留。

### 光继点

光继点是受限续航机制。它只奖励冲刺、高速或续跃状态，不应变成无限空中续航。连续触发可以有连锁反馈，但要保持路线意图清楚。

### 风升流

风升流改变空中节奏，应该让玩家提前规划高度和落点。视觉上必须有边界和上升方向提示，不能只靠试错理解。

### 超载棱镜

棱镜是高速路线的上限工具。它应该制造“安全线 vs 快线”的选择，而不是强制所有玩家只走高手线。

### 回声锚点

回声减少练习摩擦，帮助玩家在复杂房间恢复节奏。它不是撤销所有错误的保险，而是让路线练习更快重试。

首次正式出现必须先在稳定落脚面完成“激活—看懂输入—召回”，再叠加风、棱镜与脆冰。键盘、手柄和触控必须走同一召回判定；触控动作只在含回声的房间出现，不得扩成常驻 HUD。

### 脆冰

脆冰用于后段节奏压力。玩家踩上后应该能通过视觉进度和危险描边理解“立刻离开”。不要在前 6 房引入脆冰。

### 破门 / 相位台 / 巡游晶核

三者必须制造不同判断：破门要求保留冲刺并主动承诺；相位台要求读明暗节拍，且不得在玩家体内重新实体化；巡游晶核要求先看虚线轨迹再穿空档，运动必须确定、可重复。它们从 R4、R5、R7 依次教学，R8–R10 才允许组合，不得用更密的尖刺冒充机制丰富度。

## 训练内容标准

每个房间至少应该拥有：

- `target`：目标时间。
- `safe route`：稳定通关路线。
- `fast route`：更快但更难的路线。
- `expert route`：高手线，必须对应关键动作。
- `Clean` 合同：无失误完成。
- `Pace` 合同：达到 target 或目标节奏。
- `Style` 合同：房间专属动作挑战。
- `Expert` 合同：速度 + 无失误 + 关键动作验证。
- `Focus` 指标：死亡原因、失败类型、最大 split 损失、下一 Drill。

## 文案语气

文案应短、克制、像训练提示，不像教程弹窗。

推荐：

- “先稳落点，再追速度。”
- “本房建议：Clean R4，再练 Pace。”
- “最大损失来自 R7：风场后落点过低。”

避免：

- 长篇解释机制。
- 在普通游玩中持续弹出教学卡。
- 用胜负/惩罚语气评价玩家。

## 内容扩展规则

在以下条件满足前，不增加 R11+：

1. 至少完成一次 R1-R10 真人完整通关。
2. 记录每房死亡原因、看不清点、卡顿点、误触点。
3. `KNOWN_ISSUES.md` 已更新真实限制。
4. 至少跑过 `npm run check`。
5. 如果改动涉及触控、设置、练习、存档或输入，跑过 `npm run browser-smoke` 或完成等价人工覆盖。

## 后续内容方向

优先顺序：

1. 打磨 R1-R10 的可读性、难度曲线和复盘质量。
2. 补强训练文案，让每房“为什么练这一房”更清楚。
3. 继续用真实试玩校准路线 replay/ghost；当前 PB/本次路线、动作切换点和移动影子状态已可区分。
4. 完成第一章主题和视觉统一。
5. 再考虑第二组房间或新机制。

## 不扩展的内容

- 不新增第二套账号体系、公开排行榜，或让游戏玩法依赖现有可选私有云存档之外的联网服务。
- 不做第二套成就系统。
- 不做剧情长文本压过练习体验。
- 不为炫技加入无法被 `check-maps` 或人工清单验证的复杂机制。
