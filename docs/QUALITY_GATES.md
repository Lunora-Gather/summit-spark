# Quality gates

## 默认门

```bash
npm run check
```

覆盖：

- JavaScript 语法；
- 核心模块的有限时间、差值、本地云时间、评级、HTML 转义、矩形判定、距离和数值逼近行为；
- 房间模块的十房尺寸、集合对齐、嵌套只读性和终点归属；
- 粒子、残影、碎片和光轨的普通/舒缓/减少动态/低性能预算，以及万次追加压力边界；
- 山门三房与旧峰三房的当前尝试地标进度映射、未知地标闭合和损坏节点保守处理；
- 四幕环境和弦身份、Flow 升调、换幕收束/到达顺序和登顶声纹的纯数据边界；
- PB 路线中冲刺、Spark、过载及组合动作的切换提取、数量上限和移动影子语义；
- 普通游玩保持安静，并阻止已移除的死亡标记、死亡回放和失败演练空管线复活；
- 主运行时不得保留只有定义、没有消费者的函数或模块导入，以及只写不读的顶层可变状态；首次机制提示必须接入渲染与无障碍状态，同时禁止每次 Spark 重复生成文字提示；
- 样式类必须有 HTML 或运行时消费者，且顶层同选择器规则不得被后续规则完整覆盖；
- 存档模块的设置迁移、损坏 JSON 修复、数值边界、旧 Focus envelope、路线裁剪、仅限规范化白名单字段且无短哈希碰撞的精确同步比较、云冲突前的本地进度保护、档案/备份结构与失败回滚；
- 输入模块的手柄死区/阈值/漂移、方向合成、预设选择、键名显示与重复键交换；
- UI 展示模块的章节完成度、评级阈值、完整/部分幕转场成绩与收束文案、Drill/合约/路线槽标签、五类 Drill 目标/实际练习句/悬停简报、首通/PB/普通/辅助过房语义、练习优先级、练习档案/长期挑战/手柄状态摘要、单行存档导入/备份摘要、安全反馈备注/模板、四幕汇总和隐私受限本轮报告；
- 登顶建议只使用本轮已访问房间：失误优先 Clean、超目标优先 Pace、全部达标才回退长期掌握路线；
- 星顶揭示接管第四幕用时/失误证据，并清除会在揭示下方过期的分房提示；
- R7-R10 的压力必须逐房上升且单次增幅受限；R9 在首次 Echo 教学与剩余脆冰压力之间保留稳定中层回收台；
- R10 以稳定支撑的弹簧接光继回扣第一幕，并在 Style/Expert 中覆盖回声、弹簧、光继、风、棱镜和脆冰；
- 文档与目录结构；
- 单一公开入口、CSP、资源版本和 Pages 包边界；
- Appwrite 最小服务面、认证策略和私有行权限；
- 房间数据、地图、路线、Feel 和训练状态；
- GitHub Actions 完整 SHA 固定；
- 本地 HTTP 安全头、方法限制和文件白名单。
- 版本化 ES 模块的路径、MIME 类型和公开资源白名单。

默认门不依赖浏览器可执行文件，适合 CI。

## 浏览器门

```bash
npm run browser-smoke
```

覆盖真实点击、键盘、Canvas 位移、账号恢复、OTP/密码流程 mock、云冲突、1MB 存档、原子回滚、移动端安全区、软键盘、焦点陷阱、手柄死区、低性能渲染预算，以及游戏中隐藏设置/练习面板的零 DOM 变更。

以下区域改动必须运行浏览器门：

- `public/index.html` 或 `public/summit-spark.css`；
- 输入、存档、账号、云同步；
- 设置/练习/登顶面板；
- 移动端或可访问性；
- 游戏循环、Canvas 尺寸或渲染。

## 人工门

自动化不能替代：

- 实体触控和手柄手感；
- 音量与疲劳感；
- R1–R10 连续通关和难度曲线；
- 真实 Appwrite 邮件流程。

详见 `PLAYTEST_CHECKLIST.md` 和 `KNOWN_ISSUES.md`。

## 发布门

发布前至少完成：

1. `npm run check`
2. `npm run browser-smoke`
3. `git diff --check`
4. `node tools/export-room-data.js --check`
5. 确认 `public/index.html` 版本号与 CSS/JS query 一致
6. 确认 Pages workflow 只复制 `public/`
7. 确认 Pages workflow 的外部 Action 固定到完整 SHA，并原生使用 Node 24，不依赖旧版 Node 20 兼容覆盖
8. 推送后等待 GitHub Pages workflow 成功，且不出现 Node 20 Action 弃用警告
9. 运行 `npm run live-check`，逐文件核对线上构建号、CSP、版本化资源、账号 SDK 与本地 `public/` 内容
10. 打开线上版本一次，确认开始按钮与 Canvas；只有账号或部署配置变化时才重复真实邮件流程

失败时保留日志和最小复现，不通过跳过检查或删除断言来“修复”。
