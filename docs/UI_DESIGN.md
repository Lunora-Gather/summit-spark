# 界面设计约定

## 方向：月夜山景里的攀登入口

山景是主角。首屏与主菜单共用无外框的启动构图：英文小标、暖金游戏标题、一个金色主操作、雾青次操作。首次选择仅补充“选择游玩方式”和本地/云端存档说明，不再出现独立的后台式白色选择框，不使用无语义的 S 图标。

账号表单是独立任务，使用一张浅色面板；设置与练习继续按需展开。保留浅色网页环境、桌面宽度上限、原小人和固定发色，不修改地图、镜头和玩法渲染。

## 布局与状态

- 启动界面共用 `.launch-surface`，标题与按钮样式只有一个最终定义。金色表示开始，雾青表示次级入口；焦点环独立保留，不以取消键盘可见性换取简洁。
- 首次自动聚焦不显示装饰圈；首次键盘输入后显示内侧深青细线。禁止恢复外扩双圈与描边阴影，焦点本身和 Tab/Enter 操作不受影响。
- 桌面菜单以游戏容器宽度（cqw）定比例，不随浏览器留白盲目变大：主按钮宽 300–400px，标题 48–76px；手机按钮仍上限 320px。设置面板宽 440px，单张雾色纸面内使用细分隔线/17px 线性图标，反馈与存档另留 16px 分组间距。
- 滑块旁显示百分比或触控像素，首次载入、输入变化及重新打开时同步数值与 `aria-valuetext`，不改动设置取值与存档结构。
- 启动使用月夜山口插画，桌面标题放在左侧山谷，竖屏取月亮和山峰。插画未载入时可直接操作菜单。登顶保留本关实景。矮横屏把练习、设置和云存档并排，给继续训练留出一整行。
- 账号页桌面宽 430px，标题和表单共用 28px 左边线，左右等距；滚动条只在需要滚动时出现，避免空槽令内容偏左。窄屏保留安全区，账号表单居中且最宽 430px，输入文字至少 16px。矮横屏收紧标题栏，表单内部滚动，关闭键始终可达。
- 表单字段与按钮不小于 44px，标签/说明至少 12px，标签至输入框 7px，字段组之间 16px。说明自然换行，底部状态只用一条分隔线。
- 错误为深红、成功为深绿，并保留明确文字；普通文字样式不得覆盖状态语义。
- 登录模式切换、返回入口、真实错误长文案、首次进入、刷新、横竖屏和软键盘高度变化都属于设计验收，不只验收默认截图。

- 首房用键帽分组展示当前设备的操作。冲刺条分成两格，空格代表已用掉的冲刺；体力耗尽时填充归零。首房操作提示使用至少 13px 的正文文字，与画布关联供辅助技术读取。提示留到首次操作，随后让出画面。高竖屏把键位提示放到路线画布上方。触屏用金色标出冲刺，两个重开按钮写明返回位置。
- 练习首页在“选择房间”旁显示已选房间。展开后先看目标和路线，可单独展开地形和训练记录。切换房间时，底部启动按钮与目标同步更新，并保留记录的展开状态。
- 登顶页先展示本轮成绩，再把建议和对应的练习按钮放在同一张卡片内。建议可随文字增高，矮横屏分两栏并保留重开入口。
- 每房使用一幅专属远景。山门三房依次是迎客松、横桥、雾中泉台，旧峰是断拱、折返崖道、双峰豁口，风峡是瀑谷和石柱长廊，星顶是高山冰湖与终点雪脊。远景缓慢跟随镜头，减少动态效果时固定取景。微光、星座、光继回应和平台在画面上另行绘制。
- 前景按连续岩层绘制。苔岩有矮草和根须，遗迹有砂岩压顶与修补痕迹，风峡有柱状断面，星顶雪檐下垂着冰棱。脆冰用贯穿裂口区分，相位台失去实体时变成断续轮廓，尖刺保留暖色尖端。
- 四幕的收集物共用琥珀色光芯，外形依次为松灯种、铜提灯、翼风铃和霜星花。计数器与练习地图沿用本幕图标。补给羽、光继断环和三棱镜分别表示恢复、接力和超载。
- 云存档冲突时并排展示两份进度和覆盖方向，方便玩家确认选择。

## 验证与维护

在本地浏览器实际查看入口、主菜单、账号验证码/密码、设置和练习。浏览器门禁验证启动页同源样式、账号左右留白、内层透明、提示颜色、窄屏可达与无溢出。自动门禁不替代构图判断；实体手机触感仍需真人验证。

维护 `summit-spark.css` 中 P308 组件区，不再为每次版本追加同组件补丁。其余历史 UI 样式分阶段整理，避免一次性重写影响游戏中的 HUD。
